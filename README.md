# Modèles de Cristal

Fichiers des modèles d'agrandissement d'images téléchargés par l'app Android **Cristal**.
Les fichiers sont dans la release [`v1`](../../releases/tag/v1), identiques aux originaux (empreintes dans `SHA256SUMS.txt`).

Chaque modèle reste la propriété de son auteur et est redistribué ici selon sa licence.
